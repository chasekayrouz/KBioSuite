Description & interpretation
Each row is an independent profile match. Start/End give the outer span of repeated segments. HMMER statistics are full-sequence values; CDD rows use the best HSP. Alignment statistics describe the selected HSP. Compare bitscores within a source.






Annotate files
Choose protein FASTA and/or GenBank files with existing CDSs. Each input produces its own output file(s).
    

    Follows the first input’s folder until you choose or type a destination. Your choice is kept for this app session.
    

    Applies to all GenBank inputs in this run. Protein FASTA inputs produce CSV tables. Open CSV in Excel with identifier columns imported as text.
    

    For large batches: keep completed search groups locally after Stop or a crash. Run the same inputs, destination, threads and output choice again with this selected to resume. Changed inputs or settings are rejected. Checkpoints contain sequences and evidence and remain until you remove them.
    

    Existing outputs are preserved. Choose another folder to run again. Keep original GenBank files: annotation replaces functional CDS qualifiers in the GenBank output copy.
