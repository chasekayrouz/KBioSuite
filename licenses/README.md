## Source availability

Gemmi, certifi and tantan (part of MMseqs2) are licensed under MPL-2.0. KBioSuite
does not modify them, and their files remain under MPL-2.0. Their source code is
available from the versioned source archives listed in `inventory.json`: the Gemmi
and certifi source releases on the Python Package Index and the MMseqs2 18-8cc5c
source archive on GitHub. The only change to MMseqs2 is that its program is reduced
to the arm64 part.

## PyInstaller bootloader exception

The Python parts of Kblast, Kannotate, Kmatch and Kstack start through PyInstaller's
bootloader. It is licensed under GPL-2.0-or-later with an exception that allows it to
be combined with programs under other licenses. The exception covers the bootloader
only; the rest of each app keeps its own license.

## Not included

uv, Boltz-2, AlphaFold 3, Foldseek, PDB100 and PyMOL are not part of the apps. Kmatch
setup downloads uv, Boltz-2, Foldseek, PDB100 and, optionally, AlphaFold 3's code only
when you ask, each under its own terms. No model parameters or databases are included.
AlphaFold 3's separate parameter and output terms are described in the
[AlphaFold 3 notes](../docs/kmatch/af3.md).

## Public and synthetic fixture provenance

No clinker or clustermap.js implementation was copied into Kstack. Its public
GenBank examples originate at [gamcil/clinker examples](https://github.com/gamcil/clinker/tree/a126ee5306982858809981b79d6af3663cd2c56c/examples),
commit `a126ee5306982858809981b79d6af3663cd2c56c`, under the retained clinker MIT
notice `tests/kstack/fixtures/realistic/LICENSE.clinker`.
`tests/kstack/fixtures/manifest.json` records authoritative per-file URLs and hashes.
Examples represent Aspergillus alliaceus, A. mulundensis, A. versicolor,
Pseudomassariella vexata and the example labelled A. burnettii BGC (record organism
Aspergillus sp. CLMG-2019a). The three-record original is preserved unchanged under
`tests/kstack/fixtures/upstream/`; three single-record derivatives in `realistic/`
were written using Biopython without sequence/feature changes. Other realistic
GenBanks are byte-identical upstream files.

Synthetic GenBanks and JSON model fixtures are independently generated by
`scripts/kstack/make-fixtures.py` and backend test helpers. Benchmark recipes use
fixed seeds, synthetic 44 kb records, 30 CDSs, varied lengths/strands/order and
independent residue substitutions. Synthetic geometric application icons are
created by `scripts/kstack/create-icon.swift`.

Kmatch's small structural example and installed smoke use public RCSB PDB **1CSP
chain A**. Sequence examples/smoke also use public UniProt **P0CE47** and NCBI
**CAC44203.1**. Their public identifiers and retrieval URLs are recorded with the
respective fixtures or example recipes. Kblast's detailed public/synthetic fixture
provenance is in `tests/kblast/fixtures/README.md`.
Kannotate's `quick-search.json` qualification recipe identifies its 20-query
sources: MIBiG **BGC0000316** (CC BY 4.0), P0CE47, CAC44203.1, E. coli **U00096.3**,
and seeded synthetic sequences. No private research inputs are licensed or
distributed by this index.
